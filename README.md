# 医知有据 V2.1

本地运行的医学健康问答演示项目：1 个主控 Agent 负责意图识别、模块路由与危急症状前置拦截，4 个业务模块（医学知识问答、健康管理、用药管理、医疗导航）负责本地知识检索与数据管理；前端是单页四 Tab 页面，医疗导航可选接入高德地图 Web 服务 API 做关键字搜索。

> 本助手仅提供健康信息参考，不能替代医生诊断和治疗，也不提供个人化疾病诊断、处方或剂量建议。
> 出现危急症状请立即拨打 **120** 或前往最近医院急诊。

## 架构

```
用户输入
   ↓
Agent 主控（意图识别）
   ↓
危急症状前置拦截（胸痛、呼吸困难等，优先于一切业务模块、知识检索与大模型）
   ↓
Router（关键词规则路由）
   ↓
medical_knowledge ｜ health_management ｜ medication ｜ medical_navigation
   ↓
本地知识库 / 本地数据（仅未命中医学关键词的输入回退到通用大模型 general）
```

- Router 负责意图路由，医学知识模块以本地知识库检索回答；
- 危急症状前置拦截由主控 Agent 执行，属于项目安全机制，优先级高于路由、业务模块、知识检索与大模型；
- 大模型不是所有问题的默认答案来源，只有未命中医学关键词的闲聊输入才进入 `general` 通用问答；
- 医疗导航的实时地点搜索可选调用高德 Web 服务 API，结果只用于当次展示。

## 功能模块

| 模块 | 用途 |
| --- | --- |
| 主控 Agent | 意图识别、关键词路由、危急症状前置拦截；未命中医学关键词时由 `general` 兜底 |
| 医学知识问答 `medical_knowledge` | 知识卡 + WHO 来源知识片段（SQLite + FTS5 本地检索） |
| 健康管理 `health_management` | 健康档案、体重记录、六类健康指标（收缩压、舒张压、血糖、心率、体温、血氧） |
| 用药管理 `medication` | 手动录入用药计划与服药记录；计划可停用（保留历史）或删除（级联删除记录） |
| 医疗导航 `medical_navigation` | 手动录入的就医地点增删改查；高德关键字搜索仅当次展示，不写入数据库 |

## 配置

在项目根目录准备 `.env`，配置模型服务与地图 Key：

- `OPENAI_API_KEY`：模型服务密钥
- `OPENAI_BASE_URL`：模型服务地址
- `LLM_MODEL`：模型名称
- `AMAP_KEY`：高德地图 Web 服务 API Key，仅医疗导航实时搜索使用

`.env` 已被 `.gitignore` 忽略，请勿提交。所有 Key 只从环境变量读取，不硬编码进代码，也不写入日志或错误响应。不配置模型时，四个本地业务模块仍可离线使用，只有通用问答会失败；不配置 `AMAP_KEY` 时，实时地点搜索返回配置缺失提示，已手动保存的就医地点不受影响。

## 启动

主站默认只监听本机回环地址 `127.0.0.1:8000`：

```bash
python -B -m uvicorn agent.web_app:app --host 127.0.0.1 --port 8000
```

浏览器访问 `http://127.0.0.1:8000`。

`-B` 表示运行时不生成 `.pyc` 字节码文件。当前版本没有公网或多人部署所需的安全能力，不要把 `--host` 改为 `0.0.0.0`，也不要以多 worker 方式启动。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 单页应用：对话区 + 医学知识问答、健康管理、用药管理、医疗导航四个面板 |
| GET | `/api/health` | 健康检查，返回 `{"status":"ok"}` |
| POST | `/api/chat` | 请求体 `{"message": "...", "session_id": "..."}`，返回 `{"reply": "...", "session_id": "...", "module": "..."}` |
| DELETE | `/api/session/{session_id}` | 清除指定会话快照 |
| GET / PUT | `/api/health/profile` | 读取健康档案 / 部分更新健康档案 |
| GET / POST | `/api/health/weights` | 体重记录列表 / 新增体重记录 |
| DELETE | `/api/health/weights/{record_id}` | 删除指定体重记录 |
| GET / POST | `/api/health/metrics` | 健康指标列表（可按 `metric` 过滤）/ 新增健康指标 |
| GET / POST | `/api/medication/plans` | 用药计划列表 / 新增用药计划 |
| DELETE | `/api/medication/plans/{plan_id}` | 处理用药计划：`mode=stop` 停用并保留历史，`mode=delete` 物理删除并级联删除关联记录 |
| GET / POST | `/api/medication/logs` | 服药记录列表 / 新增服药记录 |
| DELETE | `/api/medication/logs/{log_id}` | 删除指定服药记录 |
| GET | `/api/navigation/search` | 高德关键字搜索，参数 `keywords`、`city`、`citylimit`、`types`；结果仅当次返回，不写入数据库 |
| GET / POST | `/api/navigation/places` | 已保存就医地点列表 / 新增地点 |
| GET / PUT / DELETE | `/api/navigation/places/{place_id}` | 查看 / 更新 / 删除已保存地点 |

`session_id` 可省略；省略时服务端自动生成。`module` 为本次请求命中的业务模块名。

## 医学知识库

当前知识库由两部分组成（均为 SQLite + FTS5，本地离线检索）：

- `knowledge_cards`：3 张手工整理的科普知识卡（高血压、2型糖尿病、普通感冒）；
- `knowledge_chunks`：25 条知识片段，每条都带完整来源元数据；
- `knowledge_fts` / `chunks_fts`：分别对应知识卡与知识片段的两张 FTS5 全文索引。

知识片段通过 `disease_name` 与知识卡主题关联，并携带 `scope` 字段用于人群边界控制。检索采用"强证据闸门"：只有命中主题名（含已核验别名）的检索词才会返回片段，仅出现正文关键词不会召回。

### 当前收录主题（首批 7 个）

高血压、2型糖尿病、冠心病、脑卒中、哮喘、流感、儿童肺炎。

其中儿童肺炎使用专门 `scope` 限定：**儿童肺炎来源仅用于儿童肺炎相关问答，禁止用于成人肺炎回答**。查询中出现"成人""老年人""医院获得性"等非儿童人群词时，儿童限定片段在数据库查询层就被排除，不依赖排序降权。

### 暂缓主题（4 个）

普通感冒、胃炎、过敏性疾病、成人肺炎。

"暂缓"不代表这些疾病没有知识需求，而是当前版本尚未纳入经过本项目来源审核流程的正式知识片段；查询这些主题时返回"暂未收录"提示。本项目不覆盖全部医学疾病，未收录主题一律明确提示，不猜测回答。

### 医学来源与追溯

首批正式知识片段全部来自 WHO 官方中文实况报道（source_level = 1，官方医学机构级）。每条片段携带 8 个来源字段：

`source_title`、`source_publisher`、`source_edition`、`source_section`、`source_page`、`source_level`、`source_url`、`accessed_at`。

用户获得知识回答时，可以沿以下链路完整追溯：

```
回答 → 知识片段 → 来源标题 → 来源机构 → 章节 → 原始 URL → 核验日期
```

网页来源没有页码，`source_page` 保持空值，回答中不显示页码行，也不会出现虚构章节。WHO 页面未明示内容许可协议，本项目不对 WHO 内容做任何具体许可证声明；知识片段正文是本项目人工整理的中文要点摘要，不是网页原文复制。

### 医学安全机制

1. **危急症状优先拦截**：胸痛、呼吸困难、突然口角歪斜、突然说话不清等危急输入，在路由和一切知识检索之前直接返回固定急救提示（含 120 引导），危急输入不会先进入普通知识检索；
2. **scope 硬过滤**：人群边界在 SQL 查询层过滤，不是排序降权；
3. **强证据检索**：未命中主题强证据的查询不返回片段，避免凭相似词误召回（如"过敏性疾病"不会带出哮喘片段、"心肌梗死"不会带出冠心病片段）；
4. **知识片段内容边界**：不含具体药物剂量、处方、停药/减药指导等高风险内容；
5. **不做个人化疾病诊断**：知识库只提供科普参考，不对个人做诊断结论。

### Router 医学词根与别名

Router 已支持以下医学词根进入医学知识模块：哮喘、卒中、中风、心肌梗死、心梗、梗死。

其中「中风」是已核验别名（WHO《卒中（实况报道）》正文明确写"卒中（俗称中风）"），检索时映射到「脑卒中」主题。**只有经过来源依据确认的别名才会进入映射**；「脑梗」等未经当前来源审核的说法暂不自动映射，避免凭相似词猜测医学主题。

## 已知限制

1. **仅支持单进程部署**。会话缓存、会话锁和 LRU 淘汰都在进程内存中，不支持多 worker；多 worker 会导致同一会话状态不一致。
2. **仅适用于本机单用户测试与演示**。没有完整的用户身份认证、多人数据隔离、数据加密、限流等能力，不要直接暴露到公网或局域网。
3. **Router 是关键词规则**，优先级为：医疗导航 > 用药 > 健康管理 > 医学知识。未命中任何关键词时回退到 `general` 通用问答，离线环境会返回 500。
4. **LLM 超时与重试**：单次请求超时 45 秒，最多尝试 2 次（含首次），失败后按 1 秒起指数退避；只重试临时性故障。
5. **会话生命周期**：超过 7 天未更新的会话视为过期，再次访问不会恢复旧历史；最多保留 200 个会话；单条消息最多 4000 个字符，超长返回中文 400。
6. **医学边界**：不做个人化疾病诊断，不擅自推荐具体药物或剂量，不建议自行停药或减药；涉及危急症状一律提示立即拨打 120 或前往急诊。
7. **知识库范围有限**：当前仅收录 7 个主题的正式知识片段，未收录主题（含暂缓的 4 个主题）返回“暂未收录”提示；部分俗称（如“脑梗”）未建立映射，检索不到时不做猜测回答。
8. **高德搜索的能力边界**：只做服务端 Web 服务 API 关键字搜索，不提供浏览器定位、周边搜索、路线规划、距离计算与地图渲染；没有用户坐标依据，因此不使用“最近”“离你多远”等表述；外部服务不可用时会返回中文错误提示并保留已保存地点数据。

## 数据与安全

以下是当前版本的明确边界，不代表项目已具备多用户隔离或生产级安全能力：

1. **数据存储**：使用 SQLite 保存健康档案、体重记录、健康指标（`data/health.db`）、用药计划与服药记录（`data/medication.db`）、手动录入的医疗导航地点（`data/navigation.db`）；医学知识库在首次使用时于 `data/knowledge.db` 建表并幂等同步知识卡与知识片段。
2. **高德地图**：使用服务端 Web 服务 API 做关键字搜索，不引入前端地图 SDK 或外部 CDN。
3. **POI 不落库**：高德搜索返回的 POI 仅用于当次展示，不保存、不缓存、不写入本地数据库；只有用户手动录入的就医地点才会持久化。
4. **API Key 管理**：`OPENAI_API_KEY`、`AMAP_KEY` 等密钥通过项目环境变量（`.env`）配置，不硬编码进代码，不写入日志或错误响应。
5. **业务数据全局共享**：健康档案、健康指标、体重记录、用药计划、服药记录和就医地点均未按用户隔离，所有会话读写的是同一份数据。
6. **会话不等于账号**：聊天记录按 `session_id` 区分，但没有账号认证，也没有会话归属校验；`session_id` 一旦泄露，他人可能读取甚至删除该会话。
7. **本地明文存储**：健康信息、用药信息、导航数据、聊天记录和知识库均以本地 SQLite 明文保存，未实现应用层加密。
8. **无完整身份认证与隔离**：当前没有账号体系、多人数据隔离、HTTPS、访问控制和完整隐私保护能力。
9. **仅本机单用户测试与演示**：不要在公共网络、局域网或公网环境中开放本项目；主站只以 `127.0.0.1` 作为监听地址，不要使用 `0.0.0.0`。
10. **不支持多 worker**：会话状态保存在进程内存中，只能以单进程运行，不得宣称可多 worker 部署。
11. **不要录入真实敏感信息**：请勿存入真实患者身份信息、真实病历或其他敏感个人健康信息，仅使用演示数据。

## 目录结构

```text
agent/                 主控 Agent、路由、会话存储、LLM 调用与 Web 应用入口
agent/modules/         四个业务模块、知识卡与知识片段数据、各 SQLite 封装、高德搜索客户端
agent/static/          单页前端（原生 HTML/CSS/JS，单文件 index.html）
tests/                 单元测试与接口测试
data/                  SQLite 数据库（health / medication / navigation / knowledge，运行期生成）
requirements.txt       Python 依赖（fastapi、uvicorn、httpx）
.env                   本地环境变量配置（模型服务与高德 Key）
```

`data/`、`.env`、`agent_memory.json`、`__pycache__/` 与 `*.pyc` 均不纳入版本控制。
